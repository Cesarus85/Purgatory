## Build

Open the project with Unity `6000.3.2f1` or run:

```sh
/Applications/Unity/Hub/Editor/6000.3.2f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -nographics -quit \
  -projectPath /absolute/path/to/QuestDemonMR \
  -executeMethod QuestDemonMR.Editor.QuestDemonProjectBuilder.BuildAndroidDebug \
  -logFile /absolute/path/to/unity-build.log
```

The build script creates `Assets/QuestDemonMR/Scenes/Main.unity` and writes `Builds/QuestDemonMR-debug.apk`.

The latest verified local build and its checksum are recorded in `Docs/BUILD-REPORT.md`.

## Device prerequisites

1. Enable developer mode on the Quest.
2. Complete Space Setup so MRUK can load floor, wall, and furniture geometry.
3. Connect the headset by USB and accept the ADB authorization prompt.
4. Install the APK with `adb install -r Builds/QuestDemonMR-debug.apk`.

## Controls

- Right controller trigger: fire
- Mouse click in Editor fallback: fire
- Walk physically through the configured room-scale boundary; Stage/Floor 6DoF tracking is enabled
- There is intentionally no artificial thumbstick locomotion in passthrough because it would desynchronize virtual room geometry from the real room

See `Docs/IMPLEMENTATION-PLAN.md` for architecture, gates, and the staged roadmap. The concept-art prompt is recorded in `Docs/ASSET-GENERATION.md`.
